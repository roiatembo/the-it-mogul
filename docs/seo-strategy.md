# The IT Mogul — SEO Strategy

## 1. SEO objective

SEO should help The IT Mogul attract businesses actively looking for:

- Website development
- E-commerce development
- WordPress development
- WordPress troubleshooting
- SEO services
- Custom software
- Business automation
- Website maintenance

The objective is not simply to generate traffic.

The objective is to generate **relevant business enquiries**.

Prioritize search intent that indicates a person or business has a problem that The IT Mogul can solve.

---

# 2. SEO principles

Follow these principles:

- Write for humans first.
- Target genuine search intent.
- Create useful pages rather than pages designed solely to rank.
- Avoid keyword stuffing.
- Avoid duplicate content.
- Avoid thin pages.
- Build topical authority gradually.
- Use internal linking intentionally.
- Do not make unsupported SEO claims.
- Do not guarantee rankings.

SEO should be part of the site's architecture from the beginning.

**E-commerce / online store development**

`/services/wordpress-development/`

**WordPress development and troubleshooting**

`/services/seo/`

Primary theme:

**SEO services**

`/services/custom-software/`

Primary theme:

**Custom software development**

`/services/business-automation/`

Primary theme:

**Business automation and integrations**

**Website maintenance and support**

---

# 10. Internal linking

Internal links should connect related content.

Examples:

Website Development → SEO

Website Development → Maintenance

E-commerce → Business Automation

WordPress Troubleshooting → Maintenance

Custom Software → Business Automation

SEO article → SEO service

WordPress article → WordPress service

Use descriptive anchor text.

Avoid excessive internal linking.

---

# 11. Metadata

Every important page should have:

- Unique SEO title
- Unique meta description
- Canonical URL
- Correct indexability
- Open Graph metadata where appropriate
- Social sharing metadata where appropriate

Titles should be written for both search engines and humans.

Avoid repetitive titles such as:

"The IT Mogul | Website Development | The IT Mogul"

---

# 12. Heading structure

Each page should have:

- One clear H1
- Logical H2/H3 hierarchy
- Headings that describe actual content

Do not use heading tags purely for visual styling.

Use CSS/theme.json for visual hierarchy.

---

# 13. URLs

URLs should be:

- Short
- Descriptive
- Human-readable
- Stable

Preferred:

`/services/web-development/`

Avoid:

`/services/service-page-1/`

Avoid unnecessary dates in service URLs.

Do not change established URLs without a reason.

---

# 14. Structured data

Use structured data where it genuinely helps search engines understand the website.

Potential types may include:

- Organization
- LocalBusiness where appropriate
- WebSite
- BreadcrumbList
- Article
- Service

Do not add structured data simply because it is available.

Structured data must accurately represent visible page content.

Never create fake review/rating structured data.

---

# 15. Technical SEO

The implementation should support:

- Crawlable HTML
- Fast page loads
- Mobile usability
- Semantic markup
- Accessible navigation
- Canonical URLs
- XML sitemap compatibility
- Clean URLs
- Correct robots directives
- Proper redirects where required
- Optimized images
- Good Core Web Vitals

Avoid unnecessary JavaScript that prevents important content from being rendered or crawled.

---

# 16. Performance

Performance is part of SEO and user experience.

Prioritize:

- Optimized image dimensions
- Modern image formats where appropriate
- Lazy loading
- Efficient CSS
- Minimal JavaScript
- Limited third-party scripts
- Proper font loading
- Avoiding unnecessarily large assets

Do not sacrifice performance for decorative animations.

---

# 17. Image SEO

Images should:

- Have descriptive filenames where practical
- Have appropriate alt text
- Be correctly sized
- Be compressed
- Use responsive image functionality

Alt text should describe meaningful images.

Do not stuff keywords into alt text.

Decorative images should use appropriate empty alt attributes.

---

# 18. Local business information

The website should clearly communicate relevant business information such as:

- Company name
- Location
- Contact information
- Service areas
- International availability

Information must remain consistent across the website and external business listings.

Do not invent physical offices or locations.

---

# 19. SEO conversion strategy

SEO traffic should not end at an article.

Relevant pages should provide contextual next steps.

Example:

Article:

**Why is my WordPress website slow?**

→ WordPress Troubleshooting

→ Website Performance

→ Contact The IT Mogul

Article:

**How much does a business website cost?**

→ Website Development

→ Start a Project

Article:

**What business processes should be automated?**

→ Business Automation

→ Custom Software

→ Start a Project

The goal is to turn relevant search traffic into qualified enquiries.

---

# 20. Search Console and analytics

The website should be prepared for:

- Google Search Console
- Google Analytics or another privacy-conscious analytics solution

Track meaningful conversions such as:

- Contact form submissions
- Email clicks
- Phone clicks
- WhatsApp clicks
- Project enquiries
- Primary CTA clicks

Do not optimize purely for page views.

---

# 21. SEO content standards

Every article should:

- Answer the searcher's question
- Provide useful information
- Demonstrate expertise
- Avoid unnecessary padding
- Include relevant internal links
- Have a logical CTA
- Be factually accurate
- Avoid AI-generated filler

Do not publish content solely because a keyword has search volume.

A smaller number of genuinely useful articles is preferable to hundreds of low-quality pages.

---

# 22. Geographic expansion rule

Do not mass-produce location pages.

Before creating a geographic page, determine:

1. Is there real commercial value?
2. Can we provide genuinely useful local information?
3. Do we have relevant experience or projects?
4. Is the search intent sufficiently different?
5. Would the page be useful to a visitor even if Google did not exist?

If the answer is no, do not create the page.

---

# 23. SEO success criteria

SEO success should ultimately be measured by:

- Relevant organic traffic
- Search visibility
- Qualified enquiries
- Conversion rate
- Growth of important service pages
- Growth of useful content
- Local visibility
- International visibility

Do not treat raw traffic as the primary measure of success.
